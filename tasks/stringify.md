## Описание задачи

Реализовать функцию `Stringify`, которая возвращает строковое представление переданной переменной

```go
package stringutils

type Stringifier interface {
	Stringify() string
}

func Stringify(v any) string {
	return ""
}
```

## Требования
Функция принимает тип `any` и должна корректно работать с любой переданной переменной

Необходимо написать тесты функционала и тесты производительности (Benchmark) с выводом количества аллокаций памяти

Примеры результатов
* `nil` => `nil`
* `1534` => `1534`
* `23.32` => `25.32`
* `true` => `true`
* `value` => `value`
* `[]int{1, 2, 3} => `[]int[1, 2, 3]`
* `map[string]int{"a": 1, "b": 2}` => `{"a": 1, "b": 2}`
* `[][]bool{{true}, {false}} => `[][]bool[[true], [false]]`
* `MyType{ Name: "User" }` => `MyType{ Name: "User" }`
* `&value` => `*int(12)`
...

Если переданный объект реализует интерфейс `Stringifier`, то его отображение должно создаваться через вызов этого метода.

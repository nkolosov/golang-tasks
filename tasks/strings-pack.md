# Упаковка и распаковка строки

## Описание задачи

### Распаковка строки
Необходимо написать Go функцию, осуществляющую примитивную распаковку строки, содержащую повторяющиеся символы/руны, например:

```go
package stringutils

import "errors"

var ErrInvalidString = errors.New("invalid string")

func Unpack(input string) (string, error) {
    return input, nil
}

func Pack(input string) string {
	return input
}
```

* `a4bc2d5e` => `aaaabccddddde`
* `abcd` => `abcd`
* `3abc` => `` (некорректная строка)
* `45` => `` (некорректная строка)
* `aaa10b` => `` (некорректная строка)
* `aaa0b` => `aab`
* `` => ``
* `d\n5abc` => `d\n\n\n\n\nabc`

Как видно из примеров, разрешено использование цифр, но не чисел.

В случае, если была передана некорректная строка, функция должна возвращать ошибку. 
При необходимости можно выделять дополнительные функции / ошибки.

#### Дополнительно
Реализовать поддержку экранирования через `\`

* `qwe\4\5` => `qwe45`
* `qwe\45` => `qwe44444`
* `qwe\\5` => `qwe\\\\\`
* `qw\ne` => `` (некорректная строка)

### Упаковка строки (обратное преобразование)

После повторяющихся символов записываем количество (цифры, не числа)
* `aaaabccddddde` => `a4bc2d5e`
* `aaaaaaaaaa` => `a9a`
* `aaaaaaaaaaaaaaaaaaaa` => `a9a9a2`

### Запуск проекта
Проект должен запускаться в консольном режиме, должны быть реализованы все сценарии

```shell
$ /your/app --unpack --input a4bc2d5e
$ aaaabccddddde
```

```shell
$ /your/app --pack --input aaaabccddddde
$ a4bc2d5e
```
